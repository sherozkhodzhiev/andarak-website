# Andarak website

Bilingual village website with a scroll-driven historical presentation, photo gallery, chapter music, and weather forecasts.

Start with [the project guide](PROJECT_GUIDE.md) for the folder structure, technologies, editing instructions, local commands, backend limitations, and publishing checklist.

The React application lives in `frontend/`. The basic FastAPI/MongoDB service lives in `backend/`. GitHub source updates do not by themselves confirm a production deployment.
